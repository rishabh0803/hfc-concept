# 📚 Concept Notes

Concept-wise notes that cut across individual lectures. While [`lecture/<n>/`](../lecture)
holds the runnable code per lecture, this folder captures the *ideas* — the why
and how — so they can be revisited independently of any single lecture.

## ✍️ Conventions

- One file per concept, named after the concept (`mmap.md`, `sockets.md`, ...).
- Link back to the concrete source files that demonstrate the concept.
- Keep notes short and practical — enough to reload the idea quickly later.
