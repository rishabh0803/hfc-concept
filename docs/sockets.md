# Sockets & Networking

Basic TCP/UDP client/server programming and small networking projects, aimed at
low-latency communication experiments.

## Why it matters

- Sockets are the foundation for networked, low-latency systems.
- Good place to explore blocking vs non-blocking I/O, buffering, and latency.

## Related code

- `network/client001.c`, `network/client002.c` — client samples.
- `network/server001.c`, `network/server002.cpp`, `network/server003.cpp` — server samples.
- `network/fileUpload/` — small file-transfer project.
